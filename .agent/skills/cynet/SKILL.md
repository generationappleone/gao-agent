# Cynet 360 AutoXDR — Integrated XDR

## Overview
Cynet 360 is an autonomous XDR platform integrating EPP, EDR, NDR, UEBA, and deception technology with automated investigation and response.

## Key Capabilities
- **Endpoint Protection**: NGAV + EDR
- **Network Detection**: NDR with traffic analysis
- **User Behavior Analytics**: UEBA for insider threats
- **Deception**: Decoys and honeypots
- **Automated Response**: CyOps MDR + automated playbooks

## Best Practices
- Deploy **deception decoys** across network segments
- Use **automated investigation** for alert triage
- Enable **user behavior baselines** for anomaly detection
- Integrate with **CyOps MDR** for 24/7 monitoring
