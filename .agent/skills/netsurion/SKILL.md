# Netsurion — Managed SIEM Platform

## Overview
Netsurion (formerly EventTracker) is a managed SIEM platform providing log management, threat detection, compliance reporting, and SOC-as-a-Service for mid-market organizations.

## Key Capabilities
- **EventTracker**: Core SIEM engine with log correlation
- **Managed SOC**: 24/7 security monitoring and response
- **Compliance Reporting**: PCI DSS, HIPAA, SOX, GDPR templates
- **Threat Intelligence**: Integrated threat feeds
- **Vulnerability Assessment**: Built-in scanning

## Use Cases
- Regulatory compliance monitoring (PCI, HIPAA)
- Managed security operations for SMB/mid-market
- Multi-tenant MSSP deployments
- Real-time threat detection and response

## Integration
- Syslog forwarding (UDP/TCP/TLS)
- Windows Event Log collection
- API-based log ingestion
- SNMP trap monitoring
